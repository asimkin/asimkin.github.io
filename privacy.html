Политика конфиденциальности

Действует с 25 ноября 2026 года. Относится к приложению Slides MCP (OAuth-клиент Google Cloud проекта slides-mcp).

1. Кто обрабатывает данные

Приложение используется одним человеком — владельцем Google-аккаунта, который его установил (далее «владелец»). Владелец одновременно является единственным пользователем приложения. Контакт: simkin.av.work@gmail.com.

2. Какие данные используются

  • адрес электронной почты Google-аккаунта — чтобы показать, под каким аккаунтом выполннен вход;
  • OAuth-токены доступа и обновления — для вызовов Google Slides API и Google Drive API;
  • содержимое презентаций, к которым владелец дал доступ, — только в объёме запрошенной операции.

3. Где хранятся данные

Все данные хранятся на компьютере владельца. Токены лежат в файле ~/.config/mcp-google-slides/credentials.json (права 0600). У приложения нет собственного сервера, базы данных и облачного хранилища.

4. Передача третьим лицам

Данные не продаются, не передаются и не раскрываются третьим лицам. Единственный получатель запросов — Google API, от имени владельца аккаунта. Анонимная телеметрия пакета отключена переменной ASKADS_TELEMETRY=0.

5. Срок хранения и удаление

Токены хранятся до отзыва доступа. Отозвать доступ можно в любой момент на странице myaccount.google.com/permissions или удалив указанный файл — после этого приложение теряет доступ к данным.

6. Файлы cookie и аналитика

Приложение не использует cookie, счётчики и системы веб-аналитики.

7. Изменения

Актуальная версия политики всегда доступна по этому адресу. Дата изменения указана в начале страницы.
