Условия использования

Действуют с 25 ноября 2026 года. Относятся к приложению Slides MCP.

1. Назначение

Приложение предоставляет локальный доступ к Google Slides API для одного пользователя — владельца Google-аккаунта, установившего приложение. Оно не является публичным сервисом, не поддерживает регистрацию и не предназначено для использования третьими лицами.

2. Использование

Владелец использует приложение на свой риск и обязуется соблюдать Условия использования Google API и Условия использования Google. Приложение работает только с теми файлами, к которым у владельца есть права.

3. Гарантии

Приложение предоставляется «как есть», без гарантий. Владелец отвечает за резервные копии презентаций: изменения применяются к файлам в Google Drive непосредственно.

4. Ответственность

Приложение не собирает платежей и не оказывает платных услуг. Ответственность за любые последствия использования ограничена рамками применимого законодательства.

5. Прекращение

Доступ можно прекратить в любой момент, отозвав разрешения на странице myaccount.google.com/permissions.
