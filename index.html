Slides MCP

Личный инструмент для работы с Google Slides через MCP.

Slides MCP — локальное приложение, которое запускается на компьютере владельца аккаунта и даёт AI-агенту читать и править презентации Google Slides через официальный Google Slides API. Приложение не является сервисом: у него нет сервера, нет регистрации и нет других пользователей.

Что делает

  • читает структуру и текст презентаций, доступных владельцу аккаунта;
  • вносит правки — текст, фигуры, таблицы, изображения, заметки докладчика;
  • по запросу выгружает презентацию в PDF или PPTX.

Как обращается с данными

Токен доступа Google хранится только локально, в файле с правами владельца (~/.config/mcp-google-slides/credentials.json). Содержимое презентаций никуда не передаётся, кроме запросов к API Google от имени владельца аккаунта. Подробнее — в политике конфиденциальности.
